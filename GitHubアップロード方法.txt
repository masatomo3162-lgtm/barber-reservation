【予約管理・新アイコン版のGitHub反映方法】

1. このZIPを展開します。
2. 「barber-reservation」フォルダーの中身をすべて選択します。
3. GitHubの「barber-reservation」リポジトリを開きます。
4. Add file → Upload files を選び、フォルダーの中身をアップロードします。
5. 同名ファイルは上書きし、Commit changes を押します。
6. GitHub Pagesの更新後、ページを開いて Ctrl＋F5 を押します。

【重要】
・新しいアイコンは reservation- で始まる別名ファイルに変更してあり、古いキャッシュを回避します。
・Service Workerのキャッシュ名も更新済みです。
・iPhone／iPad／Android／Windowsで以前のアイコンをホーム画面に追加済みの場合は、古いショートカットまたはインストール済みアプリを一度削除し、ページを再読込してから追加し直してください。
・予約データ・顧客データ・IndexedDBの保存形式は変更していません。
